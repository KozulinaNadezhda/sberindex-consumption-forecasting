## 2. Ключевые результаты решения

Разработан сквозной панельный алгоритм машинного обучения для прогнозирования потребительских безналичных расходов населения в разрезе 2 000+ муниципальных образований (МО) РФ и предиктивной детекции макроэкономических шоков.

### Итоговые подтвержденные метрики (Out-of-Time валидация):
* **Глобальная точность по всей РФ (2 000+ МО):** MAE = **2 212 руб.** | R² = **0.9390**.
* **Победа над базовой моделью Prophet:** CatBoost превзошел Prophet на всех 4 горизонтах и на 100% из 12 стратифицированных районов (среднее превосходство **+93.6%**).

## 3. Методология и архитектура решения

### 3.1. Преодоление разномасштабности (Target Scaling)
Муниципальные образования характеризуются сильным разбросом трат (от 15 тыс. руб. в малых МО до 180+ тыс. руб. в крупных центрах). Модель обучается предсказывать не абсолютные рубли, а коэффициент отклонения от базового чека территории:
$$\tilde{y}_{i,t} = \frac{y_{i,t}}{\text{Baseline}_i}$$
Базовый чек $\text{Baseline}_i$ рассчитывается строго на обучающей выборке (Out-of-Time), исключая заглядывание в будущее (Data Leakage). Рублевый прогноз восстанавливается обратным масштабированием: $\hat{y}_{i,t} = \hat{\tilde{y}}_{i,t} \cdot \text{Baseline}_i$.

### 3.2. Признаковое пространство (15 факторов)
* **Динамика территории:** признак локального импульса (`mo_momentum` = отношение последних 3 мес. к базе района) и историческая волатильность (`mo_volatility`).
* **Нелинейная эластичность декабря:** признак `december_elasticity` учитывает опережающий предновогодний всплеск в крупных промышленных центрах за счет выплаты годовых премий.
* **Непрерывное время:** циклическое тригонометрическое кодирование месяцев ($\sin / \cos$), устраняющее разрыв между декабрем и январем.
* **Макроэкономика и валюта:** совокупные расходы РФ (гармонизированные с Росстатом), валютный курс USD/RUB по официальному API Банка России и покупательская способность (`macro_per_usd`).

### 3.3. Анализ новостей (NLP) и гармонизация временных шкал
* **Research Corpus:** сформирован многофакторный корпус макроэкономических событий (48 верифицированных релизов по 4 столпам: решения ЦБ по ставке, инфляция Росстата, доходы/ВВП, санкции).
* **RuBERT-Sentiment:** нейросетевая оценка скалярной полярности текстов $s_i = P(\text{Positive}) - P(\text{Negative}) \in [-1; +1]$.
* **EMA-сглаживание:** асинхронный поток новостей согласован с помесячной шкалой СберИндекса через модель затухания памяти информационных шоков (EMA, $\alpha=0.60$).
* **Опережающий сигнал:** падение $Z\text{-score} < -1.5$ генерирует опережающий триггер структурного сдвига за 3–7 дней до изменения кассовых транзакций.

### 3.4. Детекция разладок и CUSUM-мониторинг
* Сравнительный бенчмарк алгоритмов библиотеки `ruptures`: метод скользящего окна `Window-based (w=3)` признан оптимальным для коротких рядов ($N \le 24$), зафиксировав структурный сдвиг осени 2024 года (`2024-09-01`) с $\text{Precision} = 1.0$ и $\text{Delay} = 0.0$ мес.
* Двусторонний замкнутый контур: предиктивный признак `is_shock_regime` в CatBoost + онлайн-мониторинг остатков модели CUSUM ($|e_t| > 2.5\sigma$), выявивший 396 локальных аномалий по РФ.

### 3.5. Бенчмарк фундаментальных моделей временных рядов (Chronos)
Проведено тестирование предобученной трансформерной модели **Amazon Chronos-T5 (Tiny)** в режиме Zero-Shot. Модель показала MAE 28 245 руб. (в 2.8 раза точнее Prophet — 79 828 руб.), однако уступила нашему CatBoost SOTA (18 059 руб.) из-за отсутствия экзогенных экономических драйверов.

## 4. Быстрый запуск и воспроизведение

### 4.1. Установка окружения
```bash
pip install -r requirements.txt

### 4.2. Автономное воспроизведение расчетов
# 1. Сборка верифицированного корпуса макро-новостей (Research Corpus)
python build_news_archive.py

# 2. Инференс RuBERT и EMA-гармонизация помесячного ряда сентимента
python news_processor.py

# 3. Расчет количественных метрик детекции разладок (Precision, Recall, F1, Delay)
python experiments.py

# 4. Запуск мастер-пайплайна (обучение, 4 горизонта, стратификация 12 МО, CUSUM)
python train.py

Все гиперпараметры, архитектура признаков и сиды зафиксированы в едином файле config.yaml (random_seed: 42).

### 4.3. Запуск интерактивного дашборда
-m streamlit run app.py
Интерфейс доступен в браузере по локальному адресу http://localhost:850
